# Security policy

## Reporting a vulnerability

Please report security issues privately by email to **hello@obsydia.tech** with the subject line "Security". Do not open a public issue.

Include what you found, the Core0 version or the URL affected, and the steps to reproduce it. We acknowledge every report within five working days and keep you informed until it is resolved.

## Scope

- Core0, all editions, including Community Edition
- The code published in this organisation
- obsydia.tech and app.obsydia.tech

## What to expect

We do not run a paid bug bounty. We will credit you in the release notes for the fix unless you ask us not to, and we will not take action against research done in good faith that avoids harm to users, their data and the service.

## Supported versions

Security fixes go into the current release. The release a page describes is stated at the top of each page in the [documentation](https://obsydia.tech/docs).
